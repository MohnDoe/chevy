# Chevy
Chevy is a Discord bot that enhance Hevy users' experience by letting them share their workout and integrate them with Discord natively.

## How it works
Using Hevy's *semi-public* API, Chevy will periodically check for new workouts or fetch needed onces. Verification is done through a code needed to be made on a specific workout (owned by Chevy).

## What it can do (so far)
Chevy can verify that a user is indeed who they say they are on Hevy. Once verified, a user can share any workout they want or simply use `/workout latest` to share the latest one.

Users can then choose what the workout would look like.

### Auto-share
Server owners can set up auto-share on their server. Chevy will then share automatically any new workout published by members of the server (who has linked their Hevy account and are opted-in).
