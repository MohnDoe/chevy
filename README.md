# Discord Bot in TypeScript

This is a simple Discord bot project scaffolded in TypeScript. It uses the popular `discord.js` library.

## Features

- Basic bot setup
- Ready for custom commands and event handling

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm
- A Discord bot token ([How to get one](https://discord.com/developers/applications))

### Setup

1. Install dependencies:
   ```sh
   npm install
   ```
2. Copy `.env.example` to `.env` and add your Discord bot token.
3. Start the bot:
   ```sh
   npm run dev
   ```

## Project Structure

- `src/` - TypeScript source files
- `index.ts` - Main entry point
- `.env` - Environment variables (not committed)

## Customization

Add your commands and event handlers in the `src/` directory.

This project is a starting point. For more advanced features, see the [discord.js guide](https://discordjs.guide/).
